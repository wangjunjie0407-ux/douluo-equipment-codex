# 魂环与装备物价资料库设计

## 目标

将用户提供的两张长图整理为一个可公开访问、适配电脑和手机的中文资料网站。网站包含两个一级模块：魂环资料库，以及装备物价表。用户能够快速搜索、筛选和比对条目，同时清楚识别由图片模糊造成的待核对内容。

## 数据来源与边界

- 图 1 是魂环资料表，原图尺寸为 1600 × 7810。提取魂环名称、对应年限、属性和出处。
- 图 2 是“一区物价表（2026.8）”，提取魂兽/装备/材料/魂骨名称，以及点券、龙金（组）或金币价格。
- 暗器与戒指价格不是普通物品行：需要将属性或等级区间与对应点券价格成对保存和展示。
- 不补造图片中不存在的资料。无法可靠辨认的文字保留原图上下文并标记“待核对”，不把猜测伪装成确定值。
- 价格页明确显示数据月份，避免用户把历史价格误认为实时行情。

## 信息架构

### 全局导航

页面顶部提供两个明显的模块切换入口：

1. 魂环资料库
2. 装备物价表

默认打开魂环资料库。切换模块不刷新页面，并保留当前模块的搜索条件。

### 魂环资料库

每条记录包含：

- `name`：魂环名称
- `years`：原图中的年限文本
- `yearTier`：用于筛选和配色的标准化年限层级
- `attributes`：属性或属性组合
- `source`：出处
- `confidence`：已核对或待核对
- `sourceNote`：必要时保存模糊原文说明

界面提供关键词搜索，以及年限、属性、出处筛选。桌面端使用紧凑数据表；移动端转为信息卡片，避免横向挤压。

### 装备物价表

物价记录按原图分为十万年、百万年、千万年、装备、基础材料、魂骨、暗器和戒指等分类。普通记录包含：

- `name`：名称
- `category`：分类
- `points`：点券价格
- `dragonGold`：龙金（组）价格
- `coins`：金币价格
- `notes`：组合、数量或原图补充说明
- `confidence`：已核对或待核对

没有某种计价方式时显示“—”，不显示零。物价模块提供名称搜索、分类筛选和计价方式筛选。

暗器和戒指采用区间价格结构：

- `type`：暗器或戒指
- `attributeRange`：属性/等级区间
- `minPrice`、`maxPrice`：点券价格下限与上限
- `displayPrice`：用于保留“左右”“以上”等原图语义的显示文本

这部分以阶梯对照表展示，让用户能直接从属性区间查到价格。

## 视觉设计

整体使用深色玄幻资料库风格，而不是普通办公表格。背景采用墨黑与深靛色，金色作为主强调色；魂环等级沿用红、金、绿等辨识度高的色带。卡片保留细微光晕和纹理，但正文区域维持高对比度，确保长表可读。

首屏包含网站标题、简短说明、两项模块导航和当前资料统计。主内容区突出搜索与筛选，减少装饰对大量数据浏览的干扰。交互支持键盘操作，并提供明确焦点状态。

## 数据提取与校验

1. 以原始分辨率图片为准，按表格区域切片放大识别。
2. 使用 OCR 形成初稿，再按列结构、重复格式和可见原文进行清理。
3. 对价格数字、单位、年限和专有名词进行二次检查；数字不因推测自动补齐。
4. 保留结构化 JSON 数据，使后续人工修正不需要重做页面。
5. 页面展示待核对标识，并在页尾说明数据来自图片整理。

## 技术方案

采用轻量静态站点：页面、样式、交互组件和本地 JSON 数据一同构建，无需账号、数据库或后台服务。搜索与筛选在浏览器内完成。网站以响应式布局发布到公开 HTTPS 地址。

站点包含专属 favicon、中文标题和描述。当前范围不加入用户登录、在线编辑、交易功能或实时价格抓取。

## 异常与空状态

- 搜索没有结果时显示清晰的空状态，并提供清除筛选入口。
- 缺失价格字段显示“—”。
- 待核对记录使用统一标记，悬停或点按时解释原因。
- 若某模块数据尚未完全识别，网站仍可展示已完成记录，但统计区必须标明已整理数量与待核对数量。

## 验收标准

- 两个模块均可在同一网站内切换。
- 魂环可按名称搜索，并按年限、属性和出处筛选。
- 物价可按名称搜索、分类和计价方式筛选。
- 暗器属性区间与价格具有清晰的一一对应关系。
- 电脑和手机上均无关键内容溢出，表格在小屏设备上转为可读卡片或受控滚动。
- 所有展示数据来自两张原图；不确定项被显式标注。
- 生产构建成功，并获得可公开分享的在线链接。

## 非目标

- 不制作后台管理系统。
- 不自动更新游戏市场价格。
- 不将截图中没有出现的资料从其他来源补入。
- 不把网站包装成官方数据源。
