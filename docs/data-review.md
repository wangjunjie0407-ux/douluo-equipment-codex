# 图片数据整理记录

## 来源

- 魂环资料：用户提供的 1600 × 7810 长图。
- 物价资料：一区物价表（2026.8）。

- 魂环记录：258 条。
- 普通物价：108 条。
- 暗器与戒指区间价格：22 条。
- OCR 低置信度条目统一保留 `needs-review` 状态，并在网页显示“待核对”。

## 已人工修正的高风险字段

- 天梦冰蚕/变异百万：龙金 5 组。
- 暗夜熔岩鬼：龙金 900 组。

## 使用说明

图片字号很小，OCR 仅作为录入辅助。数字、单位和表头按原图列关系整理；仍不能可靠辨认的专有名词没有强行猜测。网站中的“待核对”标记就是复核清单，后续可直接修改 `src/data` 下的 JSON 文件。
